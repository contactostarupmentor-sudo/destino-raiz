# Destino Raíz · Carta digital & reservas

Propuesta de rediseño de la carta digital del restaurante **Destino Raíz** (Plaza del Sol 35, Móstoles).

## Demo en vivo

**https://contactostarupmentor-sudo.github.io/destino-raiz/**

Repositorio: https://github.com/contactostarupmentor-sudo/destino-raiz

## Qué incluye

- Diseño **mobile-first** pensado para QR en mesa
- **Fotos reales** del menú Ágora SmartMenu
- Carta completa: ensaladas, entrantes, carnes, pescados, pizzas, burgers, bocadillos, sándwiches, tostas, postres
- Promociones del día, menús, desayunos y barra (cócteles, shishas, vinos, cervezas…)
- Buscador de platos + categorías sticky
- Galería de destacados y ficha de plato
- **Sistema de reservas** (formulario → WhatsApp / TheFork)
- Enlaces a maps, Uber Eats y carta original

## Cómo verla en local

```bash
cd destino-raiz
python3 -m http.server 8080
```
